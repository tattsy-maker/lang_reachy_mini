# T0 — Test harness & fixtures — progress notes

Status: **done** (2026-08-31). All eight tests pass on this machine with no
keys exported (`env -u ANTHROPIC_API_KEY -u GOOGLE_API_KEY tests/run.sh`:
7 passed, 1 clean skip for the missing Google key).

## What landed

- **`tests/run.sh [task-id]`** — creates `tests/.venv` (pytest,
  opencv-python-headless, numpy — a third venv, kept separate so test deps
  never touch the robot or agent trees), then runs pytest for one task's
  directory (`tests/t0/` etc.) or all of them.
- **Markers** (`robot`, `models`, `anthropic`, `google`, `audio`) declared
  in `tests/pytest.ini` and enforced in `tests/conftest.py`: a marked test
  whose prerequisite is absent skips with a printed reason (`-ra` keeps the
  reasons visible). `anthropic`/`google` accept the key from the
  environment *or* `voice/.env`, matching how `agent.py` itself resolves
  credentials — that is what makes "green with no keys exported" work.
- **Fixtures** (`tests/fixtures/`, provenance in its README): six
  public-domain NASA portraits — three people × two photos, two of the
  pairs cross-year — a synthesized 6s webcam-style clip of one of them
  (`make_video.py`, committed output), and a sample `learners/` tree
  (family + guest tier) matching spec §4B.
- **`stub_robot` fixture** — serves `controller.py --stub` on
  `tcp/127.0.0.1:7557`, waits for the `[reachy] serving` line, tears down
  with SIGINT. Verified by an attach round-trip (`slots` output).
- **`run_agent_say` fixture** — runs `voice/agent.py --no-robot --no-warmup
  --say ...` from `voice/.venv`, watches the merged log for pipecat's
  `Generating TTS [` line (the proof a reply reached synthesis), lets audio
  drain, SIGINTs. The `anthropic`-marked demo test drives one full turn.

## Learnings (things the next task should know)

1. **`agent.py --no-robot` was broken and is now fixed.** With no robot,
   `build_tools()` is skipped and the code passed `tools=None` to
   pipecat's `LLMContext`; pipecat 1.6 rejects `None` (it wants the
   argument omitted or a real list) and the agent died at startup with
   `TypeError ... Got type: <class 'NoneType'>`. The harness found this on
   its first run — the `--say --no-robot` path presumably predates the
   pipecat 1.6 pin. Fix in `voice/agent.py`: omit `tools` when the list is
   empty.
2. **Test zenoh port is 7557, not 7447.** The runbook pins live serves to
   7447; the suite uses its own port so it can run while a real robot
   session is up.
3. **Never assert on subprocess exit codes** — SIGINT'd `serve`/`agent.py`
   legitimately exit 1 (CLAUDE.md). The fixtures assert on log evidence
   instead, and `LogTail.wait_for(..., proc=...)` bails early when the
   process dies rather than waiting out the timeout (a 240s lesson).
4. **Log lines are the test API.** Readiness: `[reachy] serving` (serve),
   `ready -- say something` (agent). Reply evidence: `Generating TTS [`
   and `Bot started speaking` (pipecat DEBUG, loguru — so don't pass
   `--quiet` when the test needs them). Injection evidence:
   `injecting utterance i/n`.
5. **A full `--say` turn is cheap**: ~15s wall clock with `--no-warmup`
   (no mic input means Whisper never loads; Kokoro + one Haiku/Opus turn
   is all it pays for). Budgeted timeout stays 240s for cold caches.
6. **Fixture caveats for T2:** the two Tracy Dyson photos are from the
   same Jan 2023 sitting (easy pair); the Sunita and Scott pairs are
   cross-year (hard pairs) — use those when calibrating thresholds. The
   video clip is a synthetic pan/zoom over a still, so it exercises
   decode/rate/shape paths, not real head motion.
7. **Stub attach on a pinned localhost address is ~1s**, nothing like the
   ~4s multicast discovery the runbook warns about — pinning helps tests
   twice over.
