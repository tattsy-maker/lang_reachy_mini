# T4 — Tutor mode: briefing + memory tools — progress notes

Status: **done** (2026-08-31). `tests/run.sh t4`: 7 passed (3 fast unit
tests on the briefing, 4 live `--say` runs through the real agent with
real Claude + Kokoro). The task's stub-robot E2E was run by hand and the
written notes inspected by eye — details below.

## What landed

- **[voice/tutor_mode.py](../voice/tutor_mode.py)** — `build_briefing`
  (profile + newest-3-sessions notes → system-prompt addendum: teach in
  the profile's language regardless of what is heard, level-pitched
  guidance, correct-kindly rules, nod/shake instructions, "open where the
  notes leave off", goodbye → `save_session_notes` exactly once),
  `build_tutor_tools` (`save_session_notes` with a once-per-run guard and
  the four-section body; `update_learner_level` with validation), and
  `load_learner` (accepts folder id or display name; refuses to guess
  between two Marias — ambiguity is a startup error, not a wrong
  greeting).
- **`voice/agent.py`**: `--learner` / `--learners-root` flags; briefing
  appended to the system prompt; tutor tools registered alongside the
  motion tools; works with and without a robot.
- **Named `tutor_mode.py`, not the plan's `tutor.py`** — the repo-root
  `tutor` package (the store) owns that name on the import path.

## Verified live (all via `--say`, default Opus, real synthesis)

- 3-turn Spanish mini-lesson: replies mostly Spanish (token-count
  heuristic), the opening picked up the seeded "Next time: ask about
  Barcelona" note, and the deliberate "yo fuimos" error came back
  corrected to "fui".
- Goodbye fired `save_session_notes` once; notes gained a `Session 2`
  entry with all four bold sections; the older entry stayed intact;
  session count and last-seen advanced.
- A beginner asking in English got English scaffolding plus the Spanish
  target word.
- Clear evidence ("professional translator, ten years") got
  `update_learner_level` → profile now `advanced`.
- Stub-robot E2E by hand: media release + motion tools + tutor tools in
  one process, goodbye notes written in Spanish referencing the seeded
  hook. **This surfaced and fixed a real stub bug** — `StubTarget` never
  overrode the media-ownership methods, so `set_media_released` against a
  served stub died with `'str' object has no attribute 'release_media'`
  (the base class delegates to the vendor SDK object; the stub's `_mini`
  is the sentinel string `"stub"`). The voice agent had simply never been
  pointed at a served stub before. Fixed in `stub_target.py`.

## Learnings

1. **`--say` runs still listen on the real microphone.** Room noise
   arrived as phantom user turns mid-test (Whisper transcribed hallway
   sound as Russian, and the tutor's notes honestly said so). Tests
   passed anyway because assertions target the scripted turns, but a
   quiet room helps, and a `--deaf`/no-input flag would make scripted
   runs fully deterministic — worth considering in T10/T11.
2. **The briefing is instruction-followed well by Opus**: correction,
   note-referencing, tool discipline (exactly one save, level update only
   on explicit evidence) all held on first try. Booth-model (Haiku)
   behavior is *not* yet verified — the task notes the flag exists;
   re-check at T11's rehearsal.
3. Turn timing for tests: waiting for `injecting utterance 3/3` + a
   settle beats waiting for the first `Generating TTS` — the first-reply
   pattern ends the run before later turns execute (an early version of
   the mini-lesson test "passed" in 17s having run only one turn).
4. Live tests cost ~15–45s each; the whole T4 file is ~2 minutes. Fine
   for a task gate, too slow for a default suite — future heavy tasks
   should keep live tests to a handful.
