# T6 — Mixed-language TTS assembly — progress notes

Status: **done** (2026-08-31). `tests/run.sh t6`: 13 passed (11 parser
tests, 2 engine round-trips). DoD met: EN+ES and EN+FR round-trip with
both halves intact; tag leakage is impossible by test.

## What landed

- **[voice/spans.py](../voice/spans.py)** — the span-tag parser.
  Convention: `[es]...[/es]` around any phrase not in the reply's main
  language. Only balanced lowercase pairs with known codes become spans;
  unclosed tags, stray closers, unknown codes, nesting, and case slips
  all degrade to plain text with every tag-shaped marker stripped —
  "never spoken as brackets" is enforced by a property test over a pile
  of malformed inputs. Dependency-free, tested in the light venv.
- **Assembly in `DualEngineTTS.run_tts`** — each utterance is split into
  spans; each span synthesizes with its own engine and voice (Kokoro
  voices per language, Piper for ru/zh), stitched in order. The
  single-language common case still takes Kokoro's untouched streaming
  path (via the cleaned span text, so tags can't leak there either).
- **The tag convention lives in the base system prompt** (one
  authoritative statement, with examples), so both plain chat and tutor
  mode inherit it.
- Engine-direct helpers `synth_kokoro` / `synth_mixed` in
  `verify_language.py` power the measurement tests and T7's gate.

## Verified

- Round trips (synthesize → agent's own Whisper): *"The word for library
  is [es]la biblioteca[/es]"* → both halves transcribed; same for EN+FR
  (`la gare`) and ES+EN (`good morning`).
- Live through the real agent: asked *"How do you say the library in
  Spanish?"*, Claude tagged the answer unprompted and the log shows the
  seam exactly as designed —
  `kokoro: synthesizing 5 chars (en, voice af_heart)` →
  `13 chars (es, voice ef_dora)` → back to `en`.
- Voice pairing note: within Kokoro the per-language defaults (af_heart /
  ef_dora / ff_siwis...) are all warm female voices, so the seam is a
  timbre shift, not a character change. The Piper pair (irina / huayan)
  matches that register too. Cloud mode (T8) remains the no-seam path.

## Honest caveats (for T7)

- **EN+RU round trip is asymmetric.** The audio provably carries both
  halves (the assembly test), but plain Whisper on a mixed clip often
  keeps only the dominant/last language — our EN+RU clip came back as
  just "Спасибо большое." That is the *hearing* problem, measured and
  attacked in T7 (priming, and the per-pair report); the *speaking* MUST
  of this task is met.
- Tags spanning sentence boundaries would be split by pipecat's sentence
  chunker before reaching the parser; the prompt's examples keep tags
  within a sentence, and a split tag degrades safely to plain text.
