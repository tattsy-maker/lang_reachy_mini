# T8 — Cloud speech mode (Gemini Live) — progress notes

Status: **in progress — wired and key-ready, blocked on `GOOGLE_API_KEY`**
(2026-08-31). Everything that can be built and verified without the key
is done; the google-marked tests are written and skip cleanly today.
**To unblock: put `GOOGLE_API_KEY=...` in `voice/.env`** — then

move to done when they pass.

## What landed

- **`--speech {local,cloud}`** (default local, untouched). Cloud mode:
  - fails fast with a clear message when the key is missing (tested);
  - skips Whisper/Kokoro/Piper/Claude entirely (no Anthropic key needed);
  - builds `GeminiLiveLLMService` (pipecat's, installed via
    `pipecat-ai[google]==1.6.0` — verified to import and to leave pipecat
    1.6.0 and the local stack intact) with the same tutor briefing as
    `system_instruction` and the same motion + memory tool schemas;
  - pipeline: transport → user aggregator → gemini → embodiment →
    transport out → assistant aggregator; no local VAD/smart-turn (the
    service decides turns server-side).
- **`--gemini-model` / `--gemini-voice`** — default to pipecat's own
  (`models/gemini-2.5-flash-native-audio-preview-12-2025`); the spec's
  "Gemini 3.1 Flash Live" id should be confirmed and passed via
  `--gemini-model` once the key exists.
- **The span-tag rule is now local-mode-only** (`SPAN_TAG_RULE`): a
  speech-to-speech model has one voice for every language and would read
  the brackets aloud. Cloud's prompt instead advertises "many languages".
- **Barge-in decision (provisional):** the self-hearing mute strategies
  stay ON in cloud mode — Gemini supports full-duplex, but the robot's
  speaker and mic are centimetres apart with no echo cancellation. T11's
  booth-mic test is the place to revisit (a directional handheld mic may
  make barge-in safe).
