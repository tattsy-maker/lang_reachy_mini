## What landed

- **[voice/piper_tts.py](../voice/piper_tts.py)** — `DualEngineTTS`, one
  pipecat TTS service in the pipeline's single TTS slot: Kokoro for its
  verified languages, Piper for ru/zh, dispatched per utterance off the
  service's current language (which the router updates each turn). Same
  frame/resampler contract as the Kokoro base class. Piper 1.7.0
  installed clean from an aarch64 wheel; voices (`ru_RU-irina-medium`,
  `zh_CN-huayan-medium`, ~63 MB each) are downloaded once into
  `voice/piper_voices/` (gitignored; command in the module docstring).
- **Router extension** — `LanguageRouter(extra=...)` layers the Piper map
  over Kokoro's; `speakable()` is the one lookup both the switch guard
  and voice selection use. Whisper detection now reports non-Kokoro
  languages too (enum fallback) so a heard Russian sentence can actually
  trigger the switch.
- **[voice/verify_language.py](../voice/verify_language.py)** — the
  round-trip gate: synthesize the sentence set, transcribe with the
  agent's own Whisper (`large-v3-turbo-q4`), score normalized similarity,
  write JSON+Markdown to `tests/reports/`. `--limit` smoke mode tags its
  report so it never clobbers a recorded full run.
- `--language ru|zh` now accepted; `--piper-voices DIR` to relocate the
  models; missing models just disable those languages, nothing breaks.

## Learnings

1. **The system prompt was the last gatekeeper.** With routing done and
   Piper speaking, Claude still *refused* Russian — "You can speak
   {languages}" was baked at import from Kokoro's list. The roster is now
   formatted at startup from what the machine can actually speak. If a
   language ever "doesn't work", check what the model was told before
   checking the speech stack.
2. `mlx_whisper.transcribe(path)` needs ffmpeg (absent here); feeding a
   16 kHz float32 array (as the live pipeline does) needs nothing.
3. E2E verified through the real agent: `--language ru --deaf --say
   "Привет..."` → Claude replies in Russian → `piper: synthesizing N
   chars (ru)` per sentence. The auto-detect path (router + Whisper both
   handle ru now) has not yet been exercised with a live microphone.
