## 2026-08-31 (later): smoke test green on metal

After the `video` usermod and the Gemini key: the booth smoke test now
runs the real thing — serve + agent + camera session mode came up
(**9 s with the vendor daemon warm** — the ~40 s figure is cold-start
only), and SIGINT tore it down cleanly (robot home, media back, no
orphans). Two script bugs found and fixed by making the test honest:

1. **Append-only logs faked readiness** — `grep` over `serve.log` /
   `run.log` matched a *previous* run's "ready" lines (the exact trap the
   runbook documents). The script now only reads lines written after
   launch.
2. **The subshell ate the shutdown signal** — the agent ran inside
   `( cd voice; python … ) &`, so the trap's `kill -INT` hit the subshell
   and never reached python; orphaned serve/agent processes survived the
   first failing test run. The agent is now exec'd directly and shutdown
   stops real PIDs with bounded patience (SIGINT, never SIGKILL first).
