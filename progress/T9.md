(1 model-only state test + 4 live scripted dialogs through the real

## What landed

- **[voice/face_id.py](../voice/face_id.py)** — `identify_from_source`:
  sample the face source, average a few embeddings, match against every
  stored learner → `known` / `unsure` / `unknown` / `noface`; plus
  `capture_embedding` (the 3–5-snapshot enrollment capture) and a JSON
  CLI for tests. Placeholder/foreign-dimension embeddings in profiles are
  ignored, not crashed on.
- **`agent.py --face-source SRC`** — V4L2 index, video file, or image
  dir. At startup: known → the T4 briefing; unsure → a
  confirm-before-greeting briefing + `confirm_identity` tool; unknown or
  no face → a stranger briefing (consent wording from spec §8, then name
  + language + `enroll_new_learner`).
- **`tutor_mode.py` grew** `CurrentLearner` (a mutable identity slot all
  tools share, so notes tools work for a learner who enrolled
  mid-conversation), `enroll_new_learner` (consent-gated by prompt;
  refuses a second enrollment while someone is already being tutored),
  `confirm_identity` (returns profile + recent notes as its tool result —
  the briefing arrives mid-conversation through the tool round-trip), and
  `forget_me` (wired to the store delete; in the standard briefing too).
- **`agent.py --deaf`** — never opens the microphone; see learnings.

## Verified live (scripted, real Claude + Kokoro + InsightFace)

- Unknown face + "yes, remember me, I'm Sunita, Spanish" → consent
  question audibly asked, guest profile with a 512-dim embedding created,
  **and the same video immediately re-identifies as her** (the full loop
  the booth demo depends on).
- "No thanks" → chat happened, nothing stored.
- A deliberately blended embedding at cosine 0.35 (inside the 0.25–0.45
  ask band by construction) → agent logs `face: unsure`, asks "Maria, is
  that you?" by name, and `confirm_identity` fires on the yes.
- "Forget me" → folder gone on the spot, spoken confirmation after.

## Learnings

1. **Scripted runs must be deaf.** The open mic during `--say` runs turned
   room noise into phantom user turns (T4 saw it; here it caused real
   flakes — a duplicate enrollment and a cut-off confirmation in one full
   suite run). New `--deaf` flag disables audio input entirely; the test
   fixture passes it by default. Suite went from flaky to 42/42 twice.
2. **Duplicate tool calls happen.** The model can call
   `enroll_new_learner` twice in a session; the guard ("already tutoring
   X") turns that into a harmless no-op instead of a second folder.
   Same philosophy as T4's save-once guard: prompt discipline is real but
   not a substitute for idempotent tools.
3. **The unsure band is testable deterministically**: blend the video's
   own face embedding with orthogonal noise to hit an exact target cosine
   (0.35). No hoping a borderline photo scores borderline.
4. **Tool results are a legitimate mid-conversation briefing channel** —
   `confirm_identity` hands back profile + notes, and the model picks up
   the lesson thread from there. No context surgery needed.
