## T14.7 — enabling web search (a guide, not code)

The agent already declares Gemini's native `google_search` tool and
probes it at startup. On this key the probe fails with close code 1011
"You exceeded your current quota" — grounding on the Live API is only
served to billing-enabled projects. To turn it on:

1. Open https://aistudio.google.com → the project that issued
   `GEMINI_API_KEY` (Settings → API keys shows which Cloud project).
2. In Google Cloud console for that project: **Billing → Link a billing
   account** (a card; the pay-as-you-go tier). Grounding with Google
   Search is billed per grounded request beyond the free allowance.
3. Wait a few minutes, then run the probe:
   `tests/run.sh t8 -k google_search` — it passes when the setup with
   the tool connects, and the agent logs
   `web search: Google Search grounding enabled for Gemini` at startup
   instead of the `unavailable on this key` warning. Nothing else to
   change; the prompt line telling the model when to search is already
   there and is removed automatically while search is unavailable.
4. Optional: `--no-web-search` keeps it off for a run (a cost cap, or a
   no-internet demo).

If the family wants it before a billed key exists, a second key from a
billing-enabled project can be dropped into `voice/.env` as
`GEMINI_API_KEY`; the rest is automatic.
